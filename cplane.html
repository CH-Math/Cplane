Cplane

Cplane is inspired by PPlane, but written from scratch to be light weight and run in the browser.

It can detect and classify equilibria, and search for cycles.

  1. Enter the system equations (you can change the variable names).
  2. Define the region in the plane you'll be looking at.
  3. Press Go!
  4. Click on the phaseportrait to draw (a part of) an orbit.
  5. Shift-click to search for an (isolated) equilibrium.
  6. Ctrl-click to search for a cycle (works best if the cycle is contained in the window, and the period is not too long).
